Official Brand Identity: kart-i-on (ESTD. 2026)

Motto: “Shop the vibe. Trust the drive” — Designed by Shashwat Shukla.

Founded in 2026, BharatMart ™ is a student-friendly demonstration of how classic HTML 4.01 markup and Cascading Style Sheets (CSS) power a complete multi-page online retail store.

Our Core Values (Definition List)

1. Craftsmanship & Utility
Curating dependable study tools for students, concert-grade instruments for musicians and dancers, heritage watches, warm home decor, and smart electronics.
2. Transparent Standards
Clear policies covering Shipping, Returns, Privacy, and Terms of Service.
3. Clean Semantic Web Code
Built with readable HTML tags, attributes, tables, forms, and external stylesheets so beginners can inspect and learn every line.
